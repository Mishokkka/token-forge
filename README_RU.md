# TokenForge v1.7.1 — токены персонажей и изображения предметов

Программа для Windows 10/11. Создаёт WebP-изображения с прозрачным фоном локально, без облачной отправки артов. Для удаления фона использует rembg и модели BiRefNet; кэш вырезок работает для обоих режимов.

## Исправлено в v1.7.1: предметы никогда не обрезаются

- При всех трёх вариантах расположения предмет **целиком помещается в квадрат**, включая чёрную обводку 3 px.
- Масштаб 100% соответствует **максимальному размеру, помещающемуся без обрезки** при текущем повороте. При попытке выставить масштаб выше 100% он автоматически ограничивается максимумом, чтобы не обрезать предмет.
- Горизонтальный и вертикальный сдвиги ограничены допустимым свободным местом. Если предмет уже занимает весь размер по одному измерению, дальше сдвинуть его по этой оси без обрезки нельзя.
- В режиме «По центру» сохраняется отступ минимум ~5% от краёв, при диагоналях ~1.8%. Отступы учитывают толщину обводки.
- При подготовке вырезки сохраняются и слабые полупрозрачные пиксели, например тонкие края и волоски.
- Патч устанавливается заменой `item_engine.py` и `tokenforge.py`. Повторная установка Python, моделей или контекстного меню не требуется.

## Новое в v1.7: режим «Предметы»

В верхнем правом углу окна переключи **«Токены» / «Предметы»**.

Предметы сохраняются в **500 × 500, WebP без потерь, прозрачный фон, чёрная обводка 3 px**. Поддерживаются три композиции:

- **По центру**: без автоматического поворота, вся вырезка вписывается в квадрат с отступом примерно 5% со всех сторон.
- **Диагональ ↗**: продольная ось предмета выравнивается снизу-слева вверх-вправо. Предмет масштабируется почти до углов квадрата с небольшим защитным отступом.
- **Диагональ ↘**: аналогично, сверху-слева вниз-вправо.

В режиме предметов доступны индивидуальные регулировки масштаба, смещения и добавочного поворота. Изменения запоминаются для каждого изображения в `%LOCALAPPDATA%\TokenForge\settings.json` независимо от настроек токенов персонажей. Выбор диагонали помогает вытянутым предметам, например оружию. Для округлых предметов лучше подходит центр.

Название результата: `Меч.png` → **`Меч_item.webp`**. Если включена опция конвертации, рядом также будет `Меч.webp`, обычная WebP-копия оригинала. Исходный PNG не изменяется.

Токены персонажей по-прежнему сохраняются как `Мечt.webp`. Предметы и токены не перезаписывают друг друга. В обоих режимах готовые изображения можно открывать без повторного запуска нейросети. Извлечённые вырезки хранятся в `%LOCALAPPDATA%\TokenForge\cutouts`.

## Обновление установленной v1.7 или v1.6

1. Закрой TokenForge.
2. Распакуй `TokenForge_v1_7_1_patch.zip` в папку, где уже лежит `run.bat`. Согласись на замену файлов. Существующую `.venv` и папку кэша не удаляй.
3. Запусти `run.bat` и проверь переключатель **«Предметы»**.
4. Если обновляешься с v1.6, повторно запусти `install_context_menu.bat`, чтобы появились пункты меню для предметов. При обновлении с v1.7 повторная установка меню не требуется.

Python и зависимости повторно устанавливать не надо. Сохранённые настройки персонажей остаются на месте.

## Полная установка на Windows

1. Распакуй `TokenForge_v1_7_1_full.zip`, например в `C:\TokenForge` (в архиве уже есть папка `TokenForge`).
2. Установи Python **3.12 64-bit**, если он ещё не установлен. С Python Install Manager можно выполнить в CMD `pymanager install 3.12`; проверка: `py -3.12 --version`.
3. Запусти `install.bat`. Он создаст `.venv` и установит Pillow, rembg, ONNX Runtime и tkinterdnd2.
4. Запусти `run.bat`. При первом удалении фона нужная модель будет скачана один раз, затем будет использоваться локально.
5. По желанию запусти `install_context_menu.bat` для добавления команд в ПКМ по изображению. Он работает для текущего пользователя Windows и не требует администратора.

**Важно:** после регистрации меню не перемещай папку программы. Если перенёс, повторно выполни `install_context_menu.bat`. Для удаления пунктов меню есть `remove_context_menu.bat`.

## Контекстное меню Windows

По ПКМ по файлу PNG/JPG/JPEG/WebP/BMP/TIF/TIFF доступны:

- **Сделать автоматический токен**: прежний генератор персонажей с сохранёнными настройками.
- **Открыть в TokenForge**: открыть выделенный арт во вкладке токенов.
- **Сделать арт предмета**: автоматически создать `Имя_item.webp` без основного окна, по настройкам предметов.
- **Открыть предмет в TokenForge**: открыть этот арт сразу в редакторе предметов.

Автоматические команды используют текущую модель фона, постоянный кэш, настройки конкретного арта, опции конвертации оригинала и пропуска готового файла. Если результат уже есть и галочка **«Пропускать готовые изображения»** включена, программа не перезапишет его. Кнопка **«Сохранить выбранный»** в основном окне перезаписывает выбранный результат намеренно.

**Windows 11:** классические пункты иногда находятся под «Показать дополнительные параметры» (Shift+F10). Старые пункты v1.6 остаются, новые добавляются при повторной установке меню.

Если обработка через ПКМ завершилась с ошибкой, проверь `%LOCALAPPDATA%\TokenForge\context_actions.log`.

## Командная строка

Можно запустить и вручную из папки TokenForge:

```bat
run.bat --open "C:\Arts\Hero.png"
run.bat --auto "C:\Arts\Hero.png"
run.bat --open-item "C:\Arts\Sword.png"
run.bat --auto-item "C:\Arts\Sword.png"
```

`--open` / `--open-item`: открыть интерфейс на выбранном файле.
`--auto` / `--auto-item`: обработать один файл с сохранёнными настройками. Основное окно не открывается, появляется короткое уведомление.

## Пакетная обработка

Выбери папку, переключи режим и нажми **«Обработать всю папку»**. Каждый исходник будет обработан независимо, ошибки одного изображения не прерывают остальные. Сохранение идёт рядом с исходными файлами. Созданные `_item.webp`, `t.webp` и WebP-копии исходников не должны попадать в новую обработку при наличии исходника. Чтобы перегенерировать отдельный результат, нажми **«Сохранить выбранный»**.

Необязательно удалять фон вручную: уже прозрачные PNG/WebP можно обрабатывать без нейросети при включённой опции сохранения альфа-канала.

## Диагностика и ограничения

- Проверка установки: `check_install.bat`.
- Автотесты: `.venv\Scripts\python.exe -m unittest -v test_engine.py test_cache.py test_cli.py test_items.py`.
- Проверку поведения Windows Explorer нужно провести в самой Windows; тесты регистрации реестра используют заглушку Windows API.
- Автоматическое определение продольной оси рассчитано на вытянутые предметы. Для предметов неправильной формы можно выбрать «По центру» или поправить поворот вручную.
- Режимы удаления фона не изменились по сравнению с v1.6. На сложных исходниках качество зависит от выбранной модели.
